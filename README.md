# andersan-api - 大気汚染データAPI

andersan-api は、大気汚染に関するデータを提供する REST API です。この API は、過去の測定データと機械学習モデルによる予測データを提供し、特定の地域や日時における大気汚染状況を把握するのに役立ちます。

## 特徴

-   **実測データ**: 各都道府県の大気監視局から取得した実測データを提供します。
-   **予測データ**: 機械学習モデルを用いて、将来の酸化物 (OX) 濃度を予測します。
-   **地理院タイルベース**: 地理院タイルに基づいてデータを整理し、特定の地域やズームレベルでのデータ取得を容易にします。
-   **現在地情報**: 緯度経度から住所や地理院タイル座標を取得できます。
-   **確率換算表**: 機械学習モデルの予測値を確率分布に変換するための表を提供します。
-   **CORS 対応**: 異なるオリジンからのリクエストを許可する CORS (Cross-Origin Resource Sharing) に対応しています。
- **キャッシュ**: `diskcache` を使用して、`location` API の結果をキャッシュします。

## ファイル構成

-   `andersan-api.py`: メインの API サーバーコード。
-   `predict.py`: 機械学習モデルによる予測処理を行うコード。
- `andersan/`: 大気汚染データ取得や内挿処理を行うモジュール。

## API エンドポイント

### 実測データ

-   **`/raw/{prefecture}/{datehour}`**:
    -   **説明**: 指定された都道府県と日時の全測定局の実測値を返します。
    -   **メソッド**: `GET`
    -   **パラメータ**:
        -   `prefecture` (str): 都道府県名 (例: `kanagawa`)。利用可能な都道府県は `andersan.airmonitor.prefecture_retrievers` に定義されています。
        -   `datehour` (datetime): 日時 (ISO 8601 形式)。分以下は無視され、正時に揃えられます (例: `2024-09-03T06:00+09:00`)。
    -   **戻り値**:
        -   `data`: 測定局のデータを含む辞書。
        -   `spec`: 付加情報。
    -   **例**: `/raw/kanagawa/2024-09-03T06:00+09:00`

-   **`/tile/{zoom}/{prefecture}/{datehour}`**:
    -   **説明**: 指定された都道府県、日時、ズームレベルの地理院タイル点での実測値を返します。
    -   **メソッド**: `GET`
    -   **パラメータ**:
        -   `zoom` (int): 地理院タイルのズームレベル。
        -   `prefecture` (str): 都道府県名 (例: `kanagawa`)。利用可能な都道府県は `andersan.Neighbors` に定義されています。
        -   `datehour` (datetime): 日時 (ISO 8601 形式)。分以下は無視され、正時に揃えられます (例: `2024-09-03T06:00+09:00`)。
    -   **戻り値**:
        -   `spec`: 付加情報。
            - `X`, `Y`: タイルの座標のリスト。
            - `lon`, `lat`: タイルの緯度経度のリスト。
            - `Z`: タイルのズームレベルのリスト。
            - `timestamp`: データのタイムスタンプのリスト。
            - `items`: 測定項目のリスト。
        -   `data`: 測定値のリスト。
            - `XY`: タイルの座標のリスト。
            - `lon`, `lat`: タイルの緯度経度のリスト。
            - `NMHC`, `OX`, `NOX`, `TEMP`, `WX`, `WY`: 各測定項目の値のリスト。
    -   **例**: `/tile/12/kanagawa/2024-09-03T06:00+09:00`

### 予測データ

-   **`/ox/{model}/{prefecture}/{datehour}`**:
    -   **説明**: 指定された都道府県、日時、モデルを用いて、地理院タイル点での OX (酸化物) 濃度を予測します。
    -   **メソッド**: `GET`
    -   **パラメータ**:
        -   `prefecture` (str): 都道府県名 (例: `kanagawa`)。利用可能な都道府県は `andersan.Neighbors` に定義されています。
        -   `datehour` (datetime): 日時 (ISO 8601 形式)。分以下は無視され、正時に揃えられます (例: `2024-09-03T06:00+09:00`)。
        -   `model` (str): 予測モデル名。利用可能なモデルは以下の通りです。
            -   `v0`: `andersan0_1` (ズームレベル 12, 8 時間先まで予測)
            -   `v0a`: `andersan0_1_1` (ズームレベル 12, 24 時間先まで予測)
            -   `v1`: `andersan0_2` (ズームレベル 12, 24 時間先まで予測)
            -   `v1a`: `andersan0_2_1` (ズームレベル 12, 24 時間先まで予測)
    -   **戻り値**:
        -   `spec`: 付加情報。
            - `X`, `Y`: タイルの座標のリスト。
            - `lon`, `lat`: タイルの緯度経度のリスト。
            - `Z`: タイルのズームレベルのリスト。
            - `timestamp`: データのタイムスタンプのリスト。
            - `items`: 予測項目のリスト。
        -   `data`: 予測値のリスト。
            - `XY`: タイルの座標のリスト。
            - `lon`, `lat`: タイルの緯度経度のリスト。
            - `+1`, `+2`, ...: 1時間先、2時間先...の予測値。
    -   **例**: `/ox/v1/kanagawa/2024-09-03T06:00+09:00`

### 現在地情報

-   **`/loc/{lon}/{lat}`**:
    -   **説明**: 指定された緯度経度から、住所や地理院タイル座標を取得します。
    -   **メソッド**: `GET`
    -   **パラメータ**:
        -   `lon` (float): 経度。
        -   `lat` (float): 緯度。
    -   **戻り値**:
        -   `X` (int): 地理院タイルの X 座標。
        -   `Y` (int): 地理院タイルの Y 座標。
        -   `Z` (int): 地理院タイルのズームレベル。
        -   `address` (str): 住所。
        -   `pref` (str): 都道府県名 (アルファベット表記)。
    -   **例**: `/loc/139.6917/35.6895`

### 確率換算表

-   **`/ptable/{model}`**:
    -   **説明**: 指定されたモデルの予測値を確率分布に変換するための表を提供します。
    -   **メソッド**: `GET`
    -   **パラメータ**:
        -   `model` (str): 予測モデル名。利用可能なモデルは `/ox` エンドポイントと同じです。
    -   **戻り値**:
        -   `pandas.DataFrame` を JSON 形式に変換した文字列。
    -   **例**: `/ptable/v1`

## 依存ライブラリ

-   `fastapi`
-   `uvicorn`
-   `pandas`
-   `numpy`
-   `datetime`
-   `geopy`
-   `diskcache`
- `andersan`
- `predict`

## インストールと実行

1.  依存ライブラリをインストールします。
    ```bash
    pip install -r requirements.txt # もしくは、各ライブラリを個別にインストール
    ```
2.  API サーバーを実行します。
    ```bash
    uvicorn andersan-api:app --host 0.0.0.0 --port 8087 --reload
    ```

## 注意事項

-   予測モデルの精度は、学習データやモデルの構造に依存します。
-   各都道府県の大気監視ウェブサイトのデータ形式が変更された場合、`andersan` モジュール内のデータ取得処理を修正する必要があります。
-   `/loc` API は、`diskcache` を使用して結果をキャッシュします。
-   GPU を使用しない場合は、`os.environ["CUDA_VISIBLE_DEVICES"] = "-1"` を設定してください。
